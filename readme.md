# 골목대장 나야나 · Goodbye 2026

선택한 1안 Heritage Scoreboard를 구현한 반응형 웹앱입니다. TV는 딥그린, 모바일은 밝은 그린과 유리 느낌의 하단 내비게이션을 사용합니다. 모든 화면에서 보통 굵기의 제목과 본문, 순위로 위계를 잡습니다.

## 화면

- `/`: 매장별 합산·A/B/C 순위. 기본 화전 스크래치, 전체 매장 선택 및 선택 기억.
- `/nearest`: 전체 매장 통합 니어.
- `/search`: 합산 등록 전 코스 참가자까지 검색. 시즌합산 메뉴는 현재 숨겨 두었습니다.
- `/event`: 일정, 코스, 요강 원본, 공식 페이지와 TV 링크.
- `/tv`: TV 화면 선택. 상단 TV 보기와 사이드 메뉴에서 진입.
- `/tv/nearest`: A/B/C 각각 8행.
- `/tv/standings`: 합산 15행 + A/B/C 각각 8행. 자동 화면 회전 없음.

TV 하단의 움직이는 기록 바는 공식 상위 기록을 표시하며 일시정지할 수 있습니다. 모션 감소 설정에서는 정지합니다.

TV 우측 위 설정 버튼으로 차전·전체화면을 선택합니다. 합산·코스 TV는 화전 스크래치로 고정하며 매장 쿼리로 변경하지 않습니다. `?round=1`로 초기 차전을 지정합니다. `?preview=design`은 명확하게 예시로 표시되는 디자인 검토용 데이터이며, 실제 데이터 실패 시 대신 사용하지 않습니다.

## 데이터 기준

`server/golfzon.mjs`에서 공식 공개 GET 응답을 가져옵니다. 공식 `rank`, `isTieRank`, `totalScore`를 그대로 표시하며 등급·여성·다라운드 보정을 다시 더하지 않습니다. 이 기준은 클라이언트가 확정했습니다. 기존 포스터는 수정 예정이며 공식 원본을 보존합니다.

대회 3337, 1차전 23099, 2차전 23103. 매장 14859 / 17623. 니어는 매장 필터 없이 조회합니다. API 응답 캐시·자동 갱신 60초, 호출 제한시간 12초. 일부 실패는 빈 순위와 구분하며 이전 성공 기록이 있으면 실제 조회 시각과 함께 유지합니다. 개인 로그인이나 대회 운영 설정 변경은 하지 않습니다.

공식 시즌 API는 결선 선발을 위해 남겨 두되 현재 게시 메뉴에서는 시즌합산을 숨깁니다. 1, 2차전은 한 시즌이며 결선은 별도 일반대회입니다. 매장별 시즌 상위 15명씩과 추가 전체 시즌 상위 30위 이내 참가자를 선발합니다. 결선은 별도 대회이므로 현재 순위 연동 범위에 포함하지 않았습니다.

## 개발 및 배포 준비

`npm run dev -- --host 127.0.0.1 --port 4173`, `npm test`, `npm run build`를 사용합니다. Vite 개발·미리보기 서버는 `/api/leaderboard`를 연결합니다. Vercel 배포용 Node API와 설정을 포함하며 main 브랜치 푸시로 기존 프로젝트의 자동 배포를 사용합니다. 보호된 Sites 정적 패키징은 유지되어 있으나 그 정적 워커만 배포하면 Golfzon API는 제공되지 않습니다.

검증 결과는 `design-qa.md`에 있습니다. 1080p/4K TV와 여러 반응형 너비를 확인했습니다. 실제 TV 기기의 브라우저와 폴더블 실기기 검증은 별도로 필요합니다.
